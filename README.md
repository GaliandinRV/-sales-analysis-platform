Sales Analysis Platform

Web-приложение для управления данными интернет-магазина и анализа продаж.

Проект позволяет работать с пользователями, товарами и заказами, а также получать аналитические показатели по продажам. Приложение построено с разделением на слой работы с базой данных, бизнес-логику и веб-интерфейс.

Стек

* **Python 3.14**
* **FastAPI** — backend и web-интерфейс
* **SQLite** — база данных
* **Pandas** — обработка и анализ данных
* **NumPy** — работа с числовыми данными
* **Uvicorn** — ASGI-сервер
* **Docker**
* **Docker Compose**
* **Git / GitHub**

Возможности

Пользователи

* просмотр списка пользователей;
* поиск пользователя по ID;
* создание пользователя;
* редактирование данных пользователя;
* удаление пользователя;
* просмотр статистики покупок пользователя.

Товары

* просмотр списка товаров;
* поиск товара по ID;
* фильтрация товаров по категории;
* изменение цены и количества товара.

Заказы

* просмотр списка заказов;
* поиск заказа по ID;
* просмотр товаров конкретного заказа;
* просмотр заказов пользователя;
* создание заказа;
* изменение статуса заказа;
* удаление заказа;
* добавление и изменение позиций заказа;
* удаление позиции заказа.

Аналитика

Приложение рассчитывает основные показатели продаж:

* общее количество заказов;
* количество завершённых заказов;
* общую выручку;
* среднюю стоимость заказа;
* самый продаваемый товар;
* самый прибыльный товар;
* наименее продаваемый товар;
* пользователя с наибольшим количеством покупок;
* пользователя с наименьшим количеством покупок;
* наиболее продаваемую категорию.

Для аналитики данные из SQLite преобразуются в Pandas DataFrame, после чего выполняется обработка и расчёт показателей.

Архитектура

Проект разделён на несколько логических модулей:



main.py

Отвечает за FastAPI-приложение, маршруты и взаимодействие с пользователем.

service.py

координирует работу всех модулей и осуществляет подключение к базе данных

database.py

Отвечает непосредственно за взаимодействие с SQLite:

* SELECT;
* INSERT;
* UPDATE;
* DELETE;
* JOIN;
* GROUP BY;
* агрегатные функции;
* работу с внешними ключами.

analytics.py

Отвечает за обработку полученных данных с использованием Pandas и NumPy.

Запуск через Docker

1. Клонировать репозиторий


git clone https://github.com/robertgalandin-ctrl/sales-analysis-platform.git
cd sales-analysis-platform

2. Запустить приложение


docker compose up --build

После запуска приложение доступно по адресу:

http://localhost:8000

3. Остановить приложение


docker compose down


SQLite база подключается к контейнеру через Docker volume:


volumes:
  - ./database.db:/app/database.db


Благодаря этому данные базы сохраняются независимо от жизненного цикла контейнера.

Запуск без Docker

Для локального запуска необходимо установить зависимости:


pip install -r requirements.txt


После этого приложение можно запустить через Uvicorn:


uvicorn src.main:app --reload


Приложение будет доступно по адресу:


http://localhost:8000
